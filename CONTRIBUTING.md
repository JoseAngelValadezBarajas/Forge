# Contributing to Forge

Forge is source-available and is being developed under a dual-licensing model. Please read [`LICENSE.md`](LICENSE.md), [`COMMERCIAL-LICENSING.md`](COMMERCIAL-LICENSING.md) and [`NOTICE`](NOTICE) before proposing changes.

## Reports and proposals

Issue reports, feature proposals, design discussion and documentation suggestions are welcome. Keep reports reproducible, avoid secrets and private data, and explain the expected behavior and scope. Discussion or a proposal does not grant permission to merge code.

## Code contributions

The project is not currently accepting third-party code contributions for merge while the rights framework for future contributions is being finalized. A pull request does not assign, license or transfer copyright or commercial relicensing rights to the project, and submitting a pull request is not consent to any unreviewed CLA or contributor agreement.

Until an approved contribution agreement exists, maintainers may close code pull requests while preserving the discussion and technical proposal. The project may request a separately reviewed agreement for future code contributions; no such agreement is created by this document.

## Review expectations

Proposals should remain within the current milestone, include tests for behavior changes, preserve local-first boundaries, avoid provider credentials and avoid claims not supported by observed data. Do not add FND-01 functionality to FND-00 work.

## Licensing and attribution

Do not submit code copied from projects with unknown or incompatible terms. Identify relevant third-party material and preserve its notices. Do not claim ownership of code, assets or dependencies that belong to others. The project owner will decide whether and under which terms any future contribution is accepted.
