# Security Policy

Forge is a local-first project. Please do not disclose credentials, private data or a reproducible vulnerability with sensitive details in a public issue.

## Reporting

If GitHub Private Vulnerability Reporting is enabled for this repository, use the Security tab's private reporting flow. If that private flow is not available, open a minimal public issue requesting a private reporting channel without including exploit details, credentials or sensitive data. Do not assume that a public issue is a secure disclosure channel.

Include, when safe:

- the affected commit, release or environment;
- a concise description of the impact;
- reproduction steps or a minimal safe proof;
- affected files or endpoints; and
- any mitigation already applied.

Remove secrets and personal data before sending a report. Do not test against systems or data you do not own or have permission to assess.

## Response

The project will review reports as resources permit. This policy makes no response-time, remediation or disclosure guarantee. Coordinated disclosure and any public advisory will be handled after the issue has been understood and a mitigation decision has been made.

For licensing or commercial questions, use [`COMMERCIAL-LICENSING.md`](COMMERCIAL-LICENSING.md); do not include sensitive security details there.
