# Forge Trademarks and Project Identity

This document records the project's proposed identity policy. It does not claim that any name, logo or visual element is registered as a trademark, and it does not provide a legal opinion about trademark rights.

## Project identity

Forge is the name of this project. The Forge logo, visual identity, official repository direction and the designation of an official Forge release are maintained by the project owner. Code rights under [`LICENSE.md`](LICENSE.md) do not by themselves grant rights to use those identifiers in a way that suggests official origin, sponsorship or endorsement.

## Forks and modifications

Forks and modified distributions may describe their relationship to Forge accurately, but should clearly distinguish their own name, branding, screenshots and release identity from the official project. A modified distribution should not present itself as an official Forge release or imply endorsement by the project owner.

Unmodified references to Forge for attribution, compatibility, comparison or other lawful purposes are not restricted by this project policy. Applicable law controls.

## Commercial use

Permission to use Forge code commercially does not automatically include permission to use Forge branding. Branding permission, if any, must be addressed separately in an express written agreement.
